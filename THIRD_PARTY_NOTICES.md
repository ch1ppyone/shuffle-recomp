# Third-party notices

The `dreamcomp/` directory contains the native Dreamcast recompiler framework and its vendored
third-party dependencies. Their individual licenses and notices remain next to their source.

`third_party/cdirip/` contains CDIrip 0.6.3 by DeXT / Lawrence Williams, used to unpack CDI
images into temporary track files before launch. It is GPL-2.0; see its accompanying `LICENSE`,
`NOTICE.md` and source files. Release bundles containing its executable must provide the source.

Sonic Shuffle is not distributed by this repository. A compatible disc image must be supplied by
the user and is ignored by Git.
